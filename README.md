## 🌌 Overview

This repository houses the personal portfolio website of **Uday Trivedi**, an applied AI/ML student and builder at VIT Chennai. Built with a bespoke **cybernetic deep-space design language**, the portfolio presents academic achievements, hackathon-winning projects, technical leadership experience, and an open-source project directory across a fluid **7-panel horizontal sliding track**.

### 🌟 Key Highlights

- **Physics-driven "Living Neural Network"**: An isolated background HTML5 Canvas executing a custom PRNG seed algorithm (`mulberry32`), real-time particle packet routing, synaptic link pulsing, bokeh depth, and interactive pointer magnetics.
- **Continuous 700vw Horizontal Track**: High-precision pixel translation controlled by GSAP with easing and boundary safety, pairing zero-shift layouts with vertical overflow tolerance.
- **Tactile Cybernetic UI**: Glassmorphic frosted containers (`backdrop-filter: blur`), dynamic cursor spotlight glow layers on card hover, and kinetic navigation indicators.
- **Multi-Modal Navigation**: Seamless panel transitions through top header tabs, mouse wheel scroll-jacking with overflow detection, keyboard hotkeys (`ArrowLeft`, `ArrowRight`, `PageUp`, `PageDown`, `Home`, `End`), touch gestures, and a dedicated mobile slide-out drawer.
- **Zero Framework Bloat**: Pure vanilla web technologies (HTML5, CSS3, ES6+ JS) delivering near-instant 60fps renders without heavy bundle overhead.

## 🚀 Getting Started & Local Development

Because the site is built with modern vanilla web standards, **no build step, bundler, or package installation is required**.

### Option 1: VS Code Live Server (Recommended)
1. Open the project folder in **Visual Studio Code**.
2. Install the **Live Server** extension (`ritwickdey.LiveServer`).
3. Right-click [`index.html`](file:///c:/Portfolio/index.html) and select **"Open with Live Server"**.

### Option 2: Python Built-In HTTP Server
If you have Python installed, open your terminal inside the project directory and run:

```bash
# Python 3.x
python -m http.server 8000
```
Then visit `http://localhost:8000` in your browser.

### Option 3: Node.js `npx serve`
```bash
npx serve .
```

## ⚙️ Customization & Configuration

### 1. Adjusting the Neural Network Background (`app.js`)
The `NeuralEngine` class in [`app.js`](file:///c:/Portfolio/app.js) can be fine-tuned via options passed during mounting:

```javascript
const engine = new NeuralEngine(canvas, {
  density: 1.3,        // Node count multiplier
  greenAmount: 1.9,    // Proportion of accent green/cyan packets
  interaction: 2,      // Mouse attraction radius & reactivity
  packets: 1,          // Data packet firing frequency
  firingRate: 1,       // Frequency of neural link pulses
});
```

### 2. Styling & Theme Color Variables (`style.css`)
Global color schemes, glowing halos, and border radii are declared as CSS custom variables in [`style.css`](file:///c:/Portfolio/style.css):

```css
:root {
  --bg-space: #030712;
  --bg-card: rgba(15, 23, 42, 0.7);
  --accent-cyan: #38bdf8;
  --accent-emerald: #10b981;
  --accent-purple: #a855f7;
  --border-glass: rgba(56, 189, 248, 0.15);
}
```

## 📱 Navigation Controls

- **Mouse / Trackpad Wheel:** Vertical scrolling inside panels works naturally. When a panel is at its top or bottom boundary, scrolling smoothly slides to the adjacent panel.
- **Keyboard Navigation:**
  - `→` / `PageDown`: Slide right to next panel
  - `←` / `PageUp`: Slide left to previous panel
  - `Home`: Jump directly to Home (Panel 0)
  - `End`: Jump directly to Contact (Panel 6)
- **Touch / Mobile:** Horizontal swipe gestures slide smoothly between panels; tap the hamburger menu icon at the top right to open the drawer navigation.
